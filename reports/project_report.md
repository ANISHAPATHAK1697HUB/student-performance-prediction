# Student Performance Prediction System – Project Report

## 1. Introduction
This project focuses on analysing student academic performance using data science and machine learning techniques.

## 2. Dataset
The dataset contains 500 student records with seven attributes:
- Student ID
- Study Hours
- Attendance
- Assignments Completed
- Sleep Hours
- Previous Score
- Final Score

## 3. Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab
- GitHub

## 4. Methodology
1. Dataset loading and inspection.
2. Exploratory Data Analysis.
3. Data visualization and correlation analysis.
4. Feature selection.
5. Training and testing data splitting.
6. Linear Regression model training.
7. Student performance prediction.
8. Model evaluation.

## 5. Machine Learning Model
Linear Regression was used to predict students' final scores based on study hours, attendance, assignment completion, sleep hours and previous scores.

## 6. Model Evaluation

| Evaluation Metric | Result |
|---|---:|
| MAE | 3.62 |
| MSE | 20.71 |
| RMSE | 4.55 |
| R² Score | 0.7440 |

The model explains approximately 74.4% of the variation in final scores on the test dataset.

## 7. Conclusion
The project demonstrates the application of data analysis and machine learning in understanding student academic performance. The developed model can estimate final scores and provide insights into factors associated with academic outcomes.
